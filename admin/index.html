    YOUTUBE INTEGRADO

    Pesquisa e pré-escuta

    Pesquise, escolha e ouça dentro do estúdio. Pré-ouvir (só eu) é exclusivo do apresentador. Tocar para ouvintes envia o vídeo para a rádio.

    Configuração da pesquisa

    A pesquisa usa YouTube Data API, como no Bíblia. A chave fica salva somente neste aparelho.

    Como conseguir ou recuperar a chave do YouTube
    1. Abra o Google Cloud → Credenciais com a conta usada no Bíblia Rádio.
    2. Selecione o projeto em que você habilitou o YouTube. Abra a chave existente e copie-a. A chave salva no Bíblia fica somente naquele navegador e não vem junto com a clonagem.
    3. Se precisar criar: crie ou selecione um projeto; abra YouTube Data API v3 e clique em Ativar. Em Credenciais, use Criar credenciais → Chave de API.
    4. Nas restrições da chave, selecione Sites e adicione https://himundim-radio.vercel.app/*. Preserve os endereços existentes se a mesma chave atende o Bíblia.
    5. Em Restrições de API, escolha YouTube Data API v3. Salve, cole a chave acima e use Salvar configuração.

    Depois pesquise uma música neste painel para testar. Não envie a chave por mensagem.
